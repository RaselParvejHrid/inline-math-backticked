# Inline Math Backticked | A VS Code Extension

## Context
If a Heading in a .md file contains inline math, the math, on Github, breaks in custom TOC generated by all of the extensions I used. So, I wrote this extension.
## Features
It adds two context menus over an .md file.

1. Backtick all ``$x^2$`` to ``$`x^2`$``
1. Unbacktic all ``$`x^2`$`` to `$x^2$`

## Packaging
Packaged with `vsce package --allow-missing-repository` command.

To install `vsce`: `npm install -g @vscode/vsce`.
